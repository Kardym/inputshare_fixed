# 快捷键

下面的快捷键在你连接设备完成后可用：

| 快捷键 | 功能描述 |
| --- | --- |
| `<Alt>+<Shift>+e` | 在你的电脑和 Android 设备间切换控制 |
| `<Alt>+<Shift>+q` | 退出程序 |
| `F1` | 多任务切换 |
| `F2` | 回到桌面 |
| `F3` | 返回 |
| `F4` | 上一首歌曲 |
| `F5` | 播放 / 暂停 歌曲 |
| `F6` | 下一首歌曲 |
| `F7` | 降低音量 |
| `F8` | 提升音量 |
| `F9` | 降低亮度 |
| `F10` | 提升亮度 |
| `F11` | 熄屏 |
| `F12` | 亮屏 |
| 鼠标侧键 `X1` | 返回 |
| 鼠标侧键 `X2` | 打开通知栏 |

下面的快捷键在你连接设备完成后且没有共享输入时可用：

| 快捷键 | 功能描述 |
| --- | --- |
| `<Alt>+UP` | 向上滚动 |
| `<Alt>+DOWN` | 向下滚动 |
| `<Alt>+[` | 上一首歌曲 |
| `<Alt>+]` | 下一首歌曲 |
| `<Alt>+\` | 播放 / 暂停 歌曲 |

## 双指手势（控制 Android 时）

- 在 Android 光标所在位置按住 Alt，记住第一个触点的位置。移动光标后按住鼠标左键，两个触点同时按下；拖动控制第二个触点。
- 按住 Alt，向上滚动滚轮放大，向下滚动缩小。松开 Alt 释放所有触点。
- Alt+Shift+E 切换控制，Alt+Shift+Q 退出；这些组合键会取消当前手势。
- 需要 Android 在 `dumpsys input` 中提供 scrcpy 鼠标光标位置；无法获取坐标时不启用手势。“仅共享键盘”模式不使用触控手势。
